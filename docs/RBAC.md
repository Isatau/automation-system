# Матрица ролей и разрешений RestoCore

Разрешения вида `модуль:действие`. Проверка — на сервере (зависимость FastAPI `require_perm`); UI только скрывает недоступное.
Символ ✓ — есть, ✗ — нет. У владельца (`owner`) — все права, включая глобальные настройки и восстановление из бэкапа.

Дополнительно:
- **Персональные лимиты**: у кассира/администратора смены — `discount_limit` (%) и максимальная сумма возврата; превышение требует подтверждения старшего (`confirm_by` фиксируется в аудите).
- **Подтверждения операций**: эндпоинты отмены/возврата/переоткрытия смены принимают код подтверждения старшего пользователя; оба участника записываются в событие аудита.
- Переопределение прав конкретного пользователя — таблица `user_permissions` (grant/revoke), доступна только owner/tech_admin, каждое изменение — событие аудита `perm.changed`.
